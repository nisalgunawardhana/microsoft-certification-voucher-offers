## 📖 About the AZ-900 Certification

AZ-900 is an official Microsoft certification that measures your knowledge of cloud computing concepts and Azure architectural components such as compute, networking, and storage. It also covers the tools used to secure, govern, and administer Azure.

## 🎯 Who Is It For?

Anyone interested in the cloud. No prior Azure or cloud knowledge is required, so it suits absolute beginners, and **no coding is needed**.

## 🧠 How the Track Prepares You

The Azure Fundamentals skill track was built in collaboration with Microsoft and is mapped to the official exam content. It covers containers, virtual machines, role-based access control, pricing calculators, and more, with hands-on practice in Azure.
